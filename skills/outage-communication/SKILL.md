description: Template for a short stakeholder update during an outage or after a fix. Use when asked to write an update, announcement, or summary for users or managers.
---
# Outage communication template

```
[STATUS: Investigating | Identified | Resolved] <Service> - <one-line summary>
Impact: who is affected and how
Cause: plain-language root cause (or "under investigation")
Actions: what was done / is being done
Next update: <time> (or "No further updates, incident resolved")
```
Rules: no blame, no jargon, no guessing. State facts from the investigation.
